# 工作流开发指南 · 面向第三方开发者

> 适用版本：FrameWeave 0.3.45
> 读者：想自己搭一条片链（或改造官方模板再分享）的人。
> 读完你应该能：搭出一条从素材跑到成片的链、知道每条连线为什么这样连、能导出成
> 一个 zip 给别人一键复现。

---

## 1. 基本概念

| 概念 | 含义 |
|---|---|
| **节点** | 一个算子（读视频、切场景、写文案、配音、渲染…） |
| **端口** | 节点的类型化出入口：输入端口接上游，输出端口给下游 |
| **边** | 一条连线：`上游节点.输出端口 → 下游节点.输入端口` |
| **参数** | 用户在右侧面板填的东西（路径、模型名、时长…） |
| **工作流** | 节点 + 边 + 参数 的集合，保存后可以反复运行 |
| **模板** | 可分享的工作流包（一个 zip 里的 `workflow.json`） |

一条最小的链：

```
载入视频 ──video──► 场景切分 ──scenes──► 文案生成 ──script──► 配音 ──audio──► 渲染成片
```

---

## 2. 五分钟：从模板跑一条链

1. **左侧「我的工作流」→ 官方模板 → 「视频解说 · 影视解说全链」**（17 节点 / 35 边）；
2. 画布会出现整条链，节点和连线都已连好；
3. 找到 `载入视频` 节点 → 参数里填你的视频绝对路径；
4. 点「运行整条工作流」；
5. 等右侧「队列」跑完，在 `渲染成片` 节点详情里取 MP4。

第一次跑要注意：

- 模型类节点（ASR / TTS）会提示下载模型，缺模型时该节点会明确报「模型未就绪」；
- LLM 类节点（文案生成）需要在「设置 → LLM」里配置接口地址与密钥，或在该节点参数里
  用 `@secret:名称` 引用密钥库；
- 长链整体跑一次几分钟到十几分钟，属正常。

## 3. 搭链规则（照着做就不会卡在 422）

### 3.1 端口类型必须能连

| 源端口 | 可以连到 |
|---|---|
| `VIDEO` | `VIDEO`、`JSON`、`ANY` |
| `AUDIO` / `IMAGE` / `TIMELINE` | 同类型、`JSON`、`ANY` |
| `SCRIPT` | `SCRIPT`、`JSON`、`ANY` |
| `SEGMENTS` / `SUBTITLE` | 同类型、`JSON`、`ANY` |
| `JSON` | 几乎所有类型 |
| 任意 | `JSON`、`ANY` |

**`VIDEO` 不能直接连 `IMAGE`**——需要中间插一个抽帧节点。画布会直接拒绝这条连线。

### 3.2 每个输入端口只接一条边

一个输入端口接两条边时，最终生效的是"后画上去的那条"——看起来能跑，语义却是隐式的。
需要两个来源就**加中转节点**，或选一个节点自带两个输入端口（如 `mixed_audio_layout`
的 `rich_scenes` 与 `narration_items`）。

### 3.3 跨名连线要选对"取上游第几个输出"

多数节点有多个输出（例如 TTS 有 `audio`、`duration`、`marks`、`subtitles`、`report`）。
把 `tts.marks` 连到别的节点的 `narration_items` 时，平台要记住"取第 2 个输出"。
画布上连线时**从哪个小圆点拖出来，就记哪个**；不要用"从节点标题拖"的方式模糊连线。

如果发现下游拿到的值"类型像但内容不对"（比如拿到一个数字而不是列表），八成是这个映射错了，
删掉重连（从正确的输出端口圆点拖）。

### 3.4 必需输入

节点标了必需输入且没有默认值时，`mode=all` 运行会被 422 拦下，报「必需输入未连接」。
三种解法：

1. 连线；
2. 参数里给一个有意义的默认值（节点作者的事）；
3. 填「资产引用」字面量（部分节点支持 `@asset:...`）。

### 3.5 参数 vs 连线

同一个语义，节点可能既有输入端口又有参数（"二选一"）。规则一般是：**有连线用连线，没连线用参数**。
具体看节点说明里的文字（例如 `TTS` 的 `文案` 端口 + `直填文案` 参数）。

## 4. 运行、取消与重跑

| 操作 | 位置 | 说明 |
|---|---|---|
| 运行整条 | 顶部「运行」 | `mode=all`：全图按拓扑顺序跑 |
| 运行选中 | 选中若干节点 → 右键运行 | `mode=selection`：只跑选中节点 |
| 运行上游 / 下游 | 节点菜单 | `mode=upstream` / `downstream` |
| 取消 | 顶部停止 | 排队中 + 运行中一起取消，会清理子进程 |
| 重置节点 | 节点菜单 | 状态回 `pending`；可选「强制重算」（同时清该节点缓存） |
| 断点续跑 | 顶部「继续运行」 | 从上次失败的节点接着跑 |

API 等价写法：

```bash
# 运行
curl -X POST http://127.0.0.1:8788/api/workflows/<wfid>/run \
     -H "Content-Type: application/json" -H "X-FW-Local-Token: <token>" \
     -d '{"mode":"all"}'
# → {"ok":true,"task_id":"...","queue_position":1}

# 取消 / 单节点强制重算
curl -X POST http://127.0.0.1:8788/api/workflows/<wfid>/cancel
curl -X POST http://127.0.0.1:8788/api/workflows/<wfid>/nodes/<nid>/reset \
     -H "Content-Type: application/json" -d '{"force":true}'
```

> `run` 返回 200 只代表**入队成功**。要等结果，轮询
> `GET /api/workflows/<wfid>`（看每个节点的 `status` / `state`）或 `GET /api/jobs`。

## 5. 缓存：为什么有时"秒完成"

平台按「节点类型 + 版本 + 参数 + 上游产物」算缓存键：**输入没变就不重跑**，节点显示 `cached`。
这是正常行为，不是没执行。

需要强制重跑：

1. 改任意参数（哪怕改回来再改）；
2. 节点菜单「重置并强制重算」；
3. 改工作流结构（新增/删除上游节点会让下游失效）。

⚠️ 一个坑：**上一轮"成功但产出为空"也会被缓存**。如果发现"改了参数没反应、产物还是空的"，
先对该节点「重置并强制重算」再跑。

## 6. 报错怎么读

运行前的 422 是**图结构问题**，返回里带 `errors[]`：

| 报错 | 意思 | 怎么办 |
|---|---|---|
| `节点类型未注册: core/xxx` | 这个插件没装（或版本太老） | 「商城/插件」里装对应节点包 |
| `端口不存在: n5.outx` | 连线指向的端口名不存在 | 删掉这条边重连 |
| `端口类型不兼容: VIDEO -> IMAGE` | 中间缺转换节点 | 插抽帧节点 |
| `必需输入未连接: n7.video` | 该输入没连线也没默认值 | 连线 / 给默认值 / 换节点 |
| `工作流图校验失败` | 上面几类之一，看 `errors[]` 第一条 | 同上 |

运行中失败是**节点级错误**，右侧节点会显示原文，前缀含义：

| 前缀 | 含义 |
|---|---|
| `invalid: ...` | 你的输入/参数不对，改参就能过 |
| `contract: ...` | 契约冲突（缺密钥、类型不符） |
| `[xxx] ...` | 平台错误码（缺二进制、缺模型、权限拒绝…），提示里带修复建议 |

日志：应用数据目录 `logs/backend.log`；节点输出都在里面，搜节点 id 即可。

## 7. 导出与分享

### 7.1 导出一条链

界面：工作流菜单「导出」；API：

```bash
curl -OJ http://127.0.0.1:8788/api/export/workflow/<wfid> \
     -H "X-FW-Local-Token: <token>"
```

得到 `workflow.json` 打包的 zip，内容形如：

```json
{
  "name": "我的解说链",
  "version": "1.1",
  "schema_version": 1,
  "favorite": false,
  "nodes": [
    {"id": "n1", "type": "core/load_video", "x": 40, "y": 320,
     "params": {"path": ""}, "inputs": {}},
    {"id": "n2", "type": "core/scene_detect", "x": 260, "y": 320,
     "params": {"threshold": 0.8}, "inputs": {"video": "n1"}}
  ],
  "edges": [
    {"source": "n1", "target": "n2", "sourceHandle": "video", "targetHandle": "video"}
  ]
}
```

要点：

- `nodes[].type` 是**节点类型 id**（不是 `type_id` 字段名）；
- `edges[]` 四个字段齐全：`source` / `target` / `sourceHandle` / `targetHandle`；
- `inputs` 是「输入端口名 → 上游节点 id」；跨名连线建议同时在节点上写
  `"input_slots": {"narration_items": 2}` 明确"取上游第几个输出"；
- 不要把本机绝对路径写进 `params`（`载入视频` 的 `path` 留空串，让对方自己填）。

### 7.2 别人怎么用你的包

界面：「我的工作流」→「导入」→ 选 zip；或在 API：

```bash
curl -X POST http://127.0.0.1:8788/api/workflows/import \
     -H "X-FW-Local-Token: <token>" \
     -F "file=@我的解说链.zip"
```

导入后它会出现在**模板列表**里，对方点一下就能创建成可运行的工作流。
如果对方缺插件，创建时会提示缺哪些节点（`missing_type_ids`），去商城补装即可。

### 7.3 想让模板成为"官方出厂"

那属于官方仓库维护范畴（需要把 `workflow.json` 放进 `backend/app/builtin_templates/` 并随版本发布）。
社区分享用 §7.2 的导入即可。

## 8. 设计一条好链的 10 条规则

1. **一条输入端口只一条边**（避免隐式覆盖）。
2. **跨名连线显式选对输出端口**，必要时手写 `input_slots`。
3. **首节点故意留空**（`载入视频` 的路径），其余节点的默认参数必须能直接跑。
4. **媒体转换显式化**（`VIDEO→IMAGE` 插抽帧）。
5. **模型节点默认用小模型**（如 ASR `small`），大模型作为可选项并在链说明里标注体积。
6. **参数里的密钥一律 `@secret:名称`**，不要写明文。
7. **节点命名有意义**（画布上会显示节点标题，一条 17 节点的链靠命名区分职责）。
8. **给链标阶段**：装配 → 分析 → 文案 → 配音 → 字幕/布局 → 成片 → 导出，便于断点续跑。
9. **导出前清一遍绝对路径与个人配置**（模型路径、代理地址、密钥）。
10. **分享时写清前置条件**：需要哪些插件、多大模型、是否需要联网。

| 装配 | `check_models` → `text_output` | 模型预检 | — |

| | `jsm_match_visual` | 文案↔画面匹配 | 匹配阈值 |
| 音频 | `tts` | 配音 | 引擎、音色、语速 |
| | `keep_original_decision` | 原声保留决策 | 保留比例 |
| | `mixed_audio_layout` | 混音布局（静音窗/原声片段） | 原声音量、淡入淡出 |
| | `ost_select` | 原声选段 | 最小时长 |

## 10. 交付前自检清单

- [ ] `mode=all` 运行不再 422（类型、必需输入都满足）
- [ ] 每个节点的默认参数能直接跑（除了首个载入路径）
- [ ] 一条输入端口只有一条边
- [ ] 导出的 zip 里 `params` 没有本机绝对路径、没有明文密钥
- [ ] 对方机器上缺插件时能看懂「缺哪些节点」的提示
- [ ] 关键产物能在节点详情里找到（MP4/草稿/字幕）
- [ ] 链说明里写清前置条件（插件、模型、网络）

## 11. 常见故障速查

| 现象 | 首查 |
|---|---|
| 点运行立刻 422 | 错误里的 `errors[]` 第一条；多半是缺插件或缺连线 |
| 某节点一直 `pending` | 上游失败导致未触发；看上游节点错误 |
| 节点 `cached` 但产物旧 | 改参数或「重置并强制重算」 |
| 渲染出来是无声/音画不同步 | 检查 `mixed_audio_layout` 的布局输出与 `tts` 的 `marks` 是否连对 |
| 配音时长与画面不齐 | `tts` 的 `marks`（实测时长）应作为布局输入，而不是脚本估算 |
| 导出草稿缺素材 | `draft_export` 需要 video/audio/subtitle/layout 齐全 |
| 换台机器跑不动 | 模型未下、插件未装、路径失效——三件事依次查 |
