### specs/ — 内部实操规范（2026-10-26 新增）

节点与工作流的**内部**规范（讲平台内部契约：校验门编号、槽位推导、缓存键算法）原本放在平台仓
`FrameWeave/docs/specs/`，2026-10-26 迁入本目录——目标是「写节点只读一个仓」。
平台仓现在只留一行跨仓指针；平台专属契约（`平台仓不含节点源码_契约_20261026.md` 等）仍留在平台仓。

## 读法

1. **要写一个能装能跑的节点** → 先读 `插件开发指南_第三方_20261026.md`（20 分钟出包），契约定稿再对 `plugin-development-spec.md`。
2. **要搭一条链 / 分享工作流** → 读 `工作流开发指南_第三方_20261026.md`；工作流正本落本仓 `workflows/<id>/{workflow.json,meta.json}`。
3. **要查校验门编号 / 槽位推导 / 缓存键算法**（平台内部契约） → 本仓 `specs/节点开发规范_20261026.md`、`specs/工作流开发规范_20261026.md`。**平台侧**只留跨仓指针；「哪些东西归哪个仓、怎么验证」的契约在平台仓 `FrameWeave/docs/specs/平台仓不含节点源码_契约_20261026.md`。
