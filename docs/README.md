## 读法

1. **要写一个能装能跑的节点** → 先读 `插件开发指南_第三方_20261026.md`（20 分钟出包），契约定稿再对 `plugin-development-spec.md`。
2. **要搭一条链 / 分享工作流** → 读 `工作流开发指南_第三方_20261026.md`；工作流正本落本仓 `workflows/<id>/{workflow.json,meta.json}`。
3. **要查平台内部契约**（校验门编号、槽位推导、缓存键算法） → 那两个规范在**平台仓**：`FrameWeave/docs/specs/节点开发规范_20261026.md`、`FrameWeave/docs/specs/工作流开发规范_20261026.md`。

## 边界

- 本目录不放平台本体文档（构建、发布、桌面端、授权）——那些在平台仓 `FrameWeave/docs/`。
- 两份第三方指南 2026-10-26 由 `FrameWeave/docs/guides/` 迁入本仓；平台仓索引已改为指向本仓的一行指针（`FrameWeave/docs/README.md` guides 段末）。
- 新增 / 移动文档时同步更新本清单，并核对平台仓索引是否留有死链。
